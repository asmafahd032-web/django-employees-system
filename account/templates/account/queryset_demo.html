تطبيق دوال QuerySet في Django

1. all()

جميع الموظفين:

    {% for employee in all_employees %}
  • {{ employee.full_name }} - {{ employee.username }}
    • {% empty %}
  • لا يوجد موظفون.
    • {% endfor %}

2. filter()

الموظفون النشطون:

    {% for employee in active_employees %}
  • {{ employee.full_name }}
    • {% empty %}
  • لا يوجد موظفون نشطون.
    • {% endfor %}

3. exclude()

الموظفون الذين ليسوا مديرين:

    {% for employee in non_admin_employees %}
  • {{ employee.full_name }} - {{ employee.role }}
    • {% empty %}
  • لا توجد نتائج.
    • {% endfor %}

4. get()

الموظف الذي تم جلبه باستخدام اسم المستخدم:

{{ ahmed.full_name }} - {{ ahmed.email }}

5. order_by()

الموظفون مرتبين حسب الاسم:

    {% for employee in ordered_employees %}
  • {{ employee.full_name }}
    • {% endfor %}

6. count()

عدد الموظفين: {{ employee_count }}

عدد المهارات: {{ skill_count }}

7. exists()

{% if ahmed_exists %}

الموظف أحمد موجود في قاعدة البيانات.

{% else %}

الموظف أحمد غير موجود.

{% endif %}
